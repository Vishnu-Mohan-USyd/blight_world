# Dry audition assets

The 37 mono source shapes in this directory are deterministic engineering
assets generated by `tools/generate_impact_bank.py`: three variants for each
of the 11 reachable material pairs plus `rattle`, `squeak`, `chime`, and
`click`. They are damped-mode/noise synthesis, not field recordings and not
an anatomical or developmental hearing model.

The 48 kHz files are masters. The 24 kHz files use a 127-tap Kaiser-beta-8.6
low-pass at 10.8 kHz, explicit group-delay compensation, then decimation by
two. `manifest.json` records every file hash and assigns a reference peak
pressure of 0.2 Pa at one metre (about 80 dB re 20 uPa before spatial filters).
The renderer applies impact-energy, source-gain, distance, HRTF, occlusion,
and room-path scaling without clipping or automatic gain control.
